# D88 — AI provider completion and lifecycle (candidate)

Baseline: `2cb3e1695b1d872ce26f64dc5e11be597d4f02b0` (merged PR #87). One implementation PR and one combined acceptance gate G1. No acceptance matrix cells are changed merely because this code is delivered. PR #72 security approvals and previously documented deferrals remain in force.

## Provider contract

- Gemini: existing direct BYOK `gemini-2.0-flash` SDK and existing four reader prompts. No dependency or model upgrade. Cloudflare: direct user-configured HTTPS Visualize only. The image client rejects redirects instead of replaying a reading excerpt; configure the final HTTPS endpoint if the old endpoint redirected. Gateway: the existing user-configured Tailscale HTTPS `:8443/v1` base, Bearer, model alias, non-streaming `/chat/completions` payload and timeouts are preserved. No default provider fallback.
- Explicit Test Connection uses saved selected Gateway only and sends an authenticated, bodyless GET to optional `/v1/models`. Network probe budget 15 seconds; no automatic retry or inference fallback. An exact model ID in a recognized response is evidence only that the endpoint listed it. Unsupported (404/405/501), invalid response, absent model and HTTP/transport failures are distinct. An endpoint returning a catalog does not establish that credentials were enforced, the model is loaded, or chat works. Actual R7.1 support has not been verified. No endpoint hostname or key is shipped.
- Gateway transport is cancellable through OkHttp callback and response parsing. All text requests have an outer 150-second budget; the existing Cloudflare client 60-second budget remains. Gemini/Retrofit cancellation depends on their existing SDKs; stale results are suppressed and no server-side abort guarantee is claimed. Unknown SDK errors use fixed fallback text; no parsing of raw exception messages. Gemini SDK 0.9.0 exposes typed invalid-key, quota, timeout and serialization errors, but its generic ServerException may not expose HTTP status. See https://github.com/google-gemini/deprecated-generative-ai-android/blob/v0.9.0/generativeai/src/main/java/com/google/ai/client/generativeai/type/Exceptions.kt.
- AI requests select a single persisted vault, check offline before credential loading, reuse existing encrypted storage and migration under existing mutexes, and invalidate work on vault, relevant routing, offline or credential revision changes. The revision is non-secret; Gateway writes now increment it. The actual stored identity is read from the existing global DataStore, avoiding the eager StateFlow's startup default. No encryption/authentication/backup/schema changes. A request already transmitted before a settings change cannot be recalled from its server; cancellation is local/best-effort at the network boundary.
- Reader selection changes, dismiss, new book, close and composition disposal cancel selection/recap jobs. A new action replaces prior work. Recall captures the book's vault or the current global-recall vault, replaces previous recall, and clears its cached results on vault switch. No raw AI exception text is exposed in the reader. Re-press the relevant action to retry. The diagnostics panel cancels with screen disposal/dirty settings and does not persist a success badge.

## Scope boundaries and pending verification

This is a source candidate, not executed Android acceptance. No actual Gemini/Cloudflare/private Gateway calls were made during preparation; no live endpoint behavior, SDK/backend compatibility, Sonar result, or Samsung/BOOX result is claimed. A real device may not support every previously configured provider (including legacy Gemini model availability); the existing model contract is deliberately unchanged pending owner-approved migration. Existing OPDS/Keystore architecture, 60-second device authentication window, release signing, media storage, TTS, Room and CI thresholds are not changed. Do not mark a test passed on static inspection. Existing security owner deferrals remain accepted limitations, not tests passed. D89 remains separate.
